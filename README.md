# DeckClone — downloads

Instaladores do **DeckClone**, o app que clona e verifica pendrives de DJ (Rekordbox) e compara com a biblioteca do PC.

Baixe a versão mais recente em **[Releases](https://github.com/hugokaique/deckclone-releases/releases/latest)**:

| Sistema | Arquivo |
|---|---|
| Windows 10/11 | `DeckClone-Setup-<versão>.exe` |
| Mac com chip Apple (M1/M2/M3/M4) | `DeckClone-<versão>-mac-arm64.dmg` |
| Mac com Intel | `DeckClone-<versão>-mac-x64.dmg` |

Os outros arquivos de cada release (`latest*.yml`, `.zip`, `.blockmap`) são usados pela atualização automática do app.

Os instaladores ainda não são assinados:

- **Windows:** o SmartScreen mostra "editor desconhecido". Clique em *Mais informações → Executar assim mesmo*.
- **Mac:** clique com o botão direito no app → *Abrir*. Se aparecer "está danificado", rode `xattr -cr /Applications/DeckClone.app`.

Este repositório contém só os instaladores; o código-fonte fica em um repositório privado.
